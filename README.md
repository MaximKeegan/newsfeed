# 📰 News Aggregator

Учебный проект, разработанный в рамках курса **Otus Java Developer Professional**. Цель — создание backend-приложения для агрегации новостей из внешних источников, их хранения в базе данных и предоставления по запросу через JSON-RPC API. Проект развёрнут в Kubernetes и масштабируем за счёт использования нескольких реплик.

---

## 🚀 Функциональность

- Загрузка новостей из внешних источников
- Хранение данных в PostgreSQL
- Предоставление новостей через JSON-RPC API
- Работа нескольких реплик в Kubernetes
- Синхронизация реплик через `SELECT ... FOR UPDATE SKIP LOCKED`

---

## 🛠 Стек технологий

- **Java 21**
- **Spring Boot 3.4.0**
- **Spring Data JDBC**
- **PostgreSQL**
- **Flyway** — миграции БД
- **jsonrpc4j** — реализация JSON-RPC API
- **Testcontainers** — интеграционные тесты
- **Docker** — контейнеризация
- **Kubernetes** — деплой и масштабирование

---

## 🏗 Архитектура

```
[ Внешний источник новостей ]
              |
         [ Парсер ]
              |
       [ PostgreSQL DB ]
              |
     [ Backend-сервис JSON-RPC ]
        ↙               ↘
 [ Реплика 1 ]      [ Реплика 2 ]
       |                  |
   SELECT ... FOR UPDATE SKIP LOCKED
```

- **JSON-RPC** используется вместо REST в соответствии с условиями тестового задания.
- Каждая реплика безопасно извлекает новости из очереди без конфликтов с помощью SQL-блокировок.
